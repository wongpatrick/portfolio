# 🕹️ WONG_OS v8.0 — Cyberpunk 3D Interactive Portfolio

An interactive, 3D command center and portfolio website built with **Next.js 15**, **Three.js**, **Tailwind CSS v4**, **Framer Motion**, and the **Web Audio API**.

---

## 🌟 Features

- **Interactive BIOS Boot Sequence**: Retro OS startup with real-time diagnostic checks, ASCII banner, audio sweeps, and interactive mainframe entry trigger.
- **3D Isometric Workstation (Three.js WebGL)**:
  - 🖥️ **Curved Cyber Workstation** (Operator Profile & Bio)
  - 📁 **Enterprise Server Blade Rack** (Career Experience & Speed Metrics)
  - ⚡ **3-Axis Plasma Gyroscope Reactor** (Tech & Skills Matrix)
  - 🕹️ **Retro Cyber Arcade Cabinet** (Projects & Game Systems)
  - 📡 **Articulated Satellite Comms Tower** (Encrypted Transmission & CLI)
- **Circuit Board Career Timeline**: Luminous SVG circuit traces connecting career milestones with performance counters (`14s → 0.5s`, `+20% Revenue`, `45% Adoption`, `/v1/lock` soft locking).
- **The Armory (Skills Matrix)**: Filterable matrices across Core Languages, Frontend Architecture, Distributed Systems & Backend, DevOps & Observability, and Leadership & Engineering Culture.
- **The Holo Arcade**: Project showcase with 3D hover tilt cards and deep architectural inspectors (Godot 4 C# stealth engine, Local ONNX vision taggers, Slack bot).
- **In-Browser Terminal CLI**: Interactive command line interface with commands like `help`, `cat resume`, `skills`, `experience`, `projects`, `sfx`, and `whoami`.
- **Procedural Web Audio Engine**: Zero external MP3 audio files—all sound effects (key chirps, boot sweeps, hover blips, and command chimes) are generated procedurally in real-time via the browser's Web Audio API.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router) + React 19 + TypeScript
- **3D / Graphics**: Three.js (`three` + WebGL 2.0)
- **Styling**: Tailwind CSS v4 + PostCSS
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Audio**: Custom Web Audio API Synthesizer

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
